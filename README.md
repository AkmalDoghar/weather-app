# 🌤️ SkyPlus — Modern Weather Application

SkyPlus is a modern, responsive weather application built with **Next.js** and **TypeScript**. It provides current weather conditions, forecasts, hourly weather data, air quality information, and location-based weather updates through a clean and user-friendly interface.

## 🌐 Live Demo

**[skyplusweather.vercel.app](https://skyplusweather.vercel.app/)**

## ✨ Features

- 🌡️ Current weather conditions
- 📅 Daily weather forecast
- 🕐 Hourly weather forecast
- 🌧️ Rain and precipitation information
- 💨 Air quality information
- 📍 Location-based weather
- ❤️ Favorite locations
- 🔄 Compare weather between locations
- 📱 Responsive design for desktop and mobile
- ⚡ Fast and modern Next.js architecture
- 🌙 Modern weather-focused UI

## 🛠️ Tech Stack

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **Open-Meteo API**
- **Geolocation API**
- **Vercel**

## 📸 Project Overview

SkyPlus is designed to provide important weather information in one place while keeping the interface simple, responsive, and easy to use.

The application includes dedicated sections for:

- Current weather
- Forecast
- Hourly weather
- Air quality
- Favorite locations
- Weather comparison

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AkmalDoghar/weather-app.git
```

### 2. Navigate to the project

```bash
cd weather-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.
